# 임무보고서 인증샷 QR 설정 (구글 드라이브)

태블릿 주소: https://hchishj-alt.github.io/eternia-exhibition/report/

사진을 QR로 넘기려면 hchis.hj 구글 계정에 아래 스크립트를 한 번만 배포하면 됩니다. 설문 응답도 같은 스크립트가 구글 시트에 모아 줍니다.

1. https://script.google.com 접속 (hchis.hj 계정) → **새 프로젝트**
2. 기본 코드를 지우고 `apps-script.gs` 내용을 통째로 붙여넣기 → 저장
3. 위쪽 함수 선택에서 `setup` 고르고 **실행** → 권한 검토 → 계정 선택 → 고급 → 안전하지 않은 페이지로 이동 → 허용
   - 드라이브에 `ETERNIA 임무보고서 인증샷` 폴더, `ETERNIA 임무보고서 응답` 시트가 생깁니다.
4. 오른쪽 위 **배포 → 새 배포** → 유형 톱니바퀴에서 **웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
   - 배포 → 나오는 **웹 앱 URL**(…/exec) 복사
5. 그 URL을 `report/index.html`의 `window.HB_ENDPOINT = "";` 따옴표 안에 넣고 커밋

## 참고
- QR은 태블릿과 관람객 휴대폰이 둘 다 인터넷에 연결돼 있어야 작동해요.
- 사진은 드라이브 폴더에 계속 남아요. 전시 끝나고 폴더째 지우면 QR 링크도 같이 끊겨요.
- 관리자 메뉴: 화면 왼쪽 위 로고를 5번 연속 탭 (CSV 내려받기, 재전송).
