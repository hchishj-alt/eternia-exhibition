# 졸업전시 통합 기록 (records)

초대장 · 환상선택 · ETERNIA 세 사이트에서 남겨지는 기록을 **구글 시트 한 곳**에 모으는 폴더입니다.

| 시트 탭 | 무엇이 쌓이나 | 어디서 |
|---|---|---|
| 방명록 | 이름, 메시지 | 초대장 방명록 |
| 알고리즘랩 | 게시자 이름, 문장, 증폭 신호, 강도 | 환상선택 ALGORITHM LAB의 "ALGORITHM 개입시키기" |
| 이터니아 | 보상 받기(사원증·클렌징폼·톤업크림), 미션 성공 체크 | ETERNIA 관람 보상 |
| 반응 | 하트, 공유, 초대장 저장(다운로드), 일정 저장, 포스터·인스타·지도·작품 열기, 방문 | 세 사이트 전부 |

입사지원서(`application.html`)는 지금처럼 기존 입사지원서 시트에 따로 저장됩니다.

## 파일
- `record.js` 세 사이트가 같이 쓰는 기록 스크립트. **맨 위 `RECORD_URL`에 웹 앱 주소를 넣는 곳**
- `apps-script/Code.gs` 구글 시트에 붙이는 서버 코드
- `admin.html` 기록 모아보기(관리자 키 필요). 사이트별 하트·공유·저장 수, 방명록·알고리즘랩·이터니아 기록 표, CSV(엑셀) 저장

## 처음 한 번 설정 (10분)
1. 구글 드라이브에서 새 구글 시트를 만듭니다. 이름 예: `김하진 졸업전시 기록`
2. 시트 메뉴 **확장 프로그램 → Apps Script** 를 엽니다.
3. 기본 `Code.gs` 내용을 지우고 이 폴더의 `apps-script/Code.gs` 내용을 통째로 붙여 넣고 저장합니다.
4. 위쪽 함수 선택에서 **setup** 을 고르고 **실행** → 권한 허용. 아래 실행 로그에 `관리자 키: xxxxxxxx` 가 나옵니다(메모해 두세요). 시트에 탭 4개가 생깁니다.
5. 오른쪽 위 **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
   - 배포 → 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.
6. `records/record.js` 맨 위 `var RECORD_URL = '';` 따옴표 안에 그 주소를 붙여 넣고 저장 → 깃허브에 올립니다.

이제 초대장 방명록이 실제로 저장되고, 세 사이트 왼쪽 아래(이터니아는 오른쪽 가운데) 하트 버튼에 전체 하트 수가 표시됩니다.

## 기록 보기
- 구글 시트를 직접 열어도 되고,
- `…github.io/저장소이름/records/admin.html` 에서 관리자 키를 넣으면 한 화면에서 보고 CSV로 내려받을 수 있습니다.
- 부적절한 방명록은 시트 `방명록` 탭의 **숨김** 칸에 아무 글자(예: `x`)를 쓰면 초대장에서 안 보입니다.

## 참고
- 하트는 방문자(브라우저)당 사이트별 1번만 집계됩니다. 방문은 같은 탭 새로고침은 다시 세지 않습니다.
- Code.gs를 고친 뒤에는 **배포 → 배포 관리 → 수정 → 새 버전** 으로 다시 배포해야 반영됩니다(주소는 그대로).
- 관리자 키는 코드나 깃허브에 올라가지 않고 Apps Script의 스크립트 속성에만 저장됩니다.
